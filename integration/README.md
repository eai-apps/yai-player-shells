# YAiPlayer Shells

Патч `YAiPlayer-Shells.patch` применяется только к отдельной рабочей копии коммита `12e6f959002244ec7b38b896a3a191e425ec6b58` из `eai-apps/YAiPlayer`. Публикуемая объединённая тестовая сборка YAiPlayer и соответствующий исходный код, включая вошедшие в неё оболочки, предоставляются по GPLv3 (см. `COPYING`). Уведомления и лицензии сторонних компонентов в исходниках YAiPlayer сохраняются. Условия самостоятельных исходников оболочек приведены в корневом `LICENSE`.

Для исходников и сборочных скриптов нативного компонента libmpv см. upstream `ahXN00/OwnTV_libmpv` и версию зависимости в каталоге `clients/owntv-core` из архива исходников. APK Shells используют отдельные идентификаторы Android. Ранние shells-preview подписаны отладочными ключами. Начиная с канала v0.2, пакеты подписываются постоянным ключом Shells и обновляются через eai-apps/yai-player-shells. Команда сборки и параметры приведены в .github/workflows/preview.yml репозитория оболочек.
