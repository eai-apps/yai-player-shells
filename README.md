# YAi Player Shells

Vizo — интерфейс YAiPlayer для Android и Android TV. Код экранов, небольшой знак Vizo и строки интерфейса лежат в Android-библиотеке `vizo`.

Правообладатель оригинального кода — YAi. Условия использования этой копии приведены в `LICENSE`.

## Подключение

`vizo` принимает палитру, категории и действия хост-приложения. В модуле отсутствуют зависимости на OwnTV, YAiPlayer, SlyX, базы данных, аккаунты и движки воспроизведения. Адаптер YAiPlayer для каждого устройства расположен в исходниках соответствующего приложения. Для SlyX нужен адаптер к его интерфейсам.

Структура рабочей копии по умолчанию:

```text
workspace/
  YAiPlayer/
  yai-player-shells/
    vizo/
```

При другом расположении укажи путь к корню оболочек через `-Pyai.shellsDir=...`. Команды ниже запускаются из соответствующих папок `YAiPlayer/clients/android-mobile` и `YAiPlayer/clients/android-tv` на Windows:

```powershell
.\gradlew.bat :app:assembleStandardDebug "-Powntv.corePath=../owntv-core"
```

Сборкам нужны Android SDK 37 и зависимости YAiPlayer. Для воспроизводимой интеграции исходная ревизия YAiPlayer — `12e6f95`. В комплекте исходников есть патч для этой ревизии. Из корня рабочей копии его можно проверить через `git apply --check ПУТЬ_К_ПАТЧУ` и применить через `git apply ПУТЬ_К_ПАТЧУ`.

При распространении объединённой сборки YAiPlayer копия Vizo в составе этой сборки предоставляется по GPLv3 с соответствующим исходным кодом. Собственный код оболочки правообладатель может использовать в SlyX на отдельных условиях.
